# eng --> arabic ⌨️

**A Smart English-to-Arabic Keyboard Layout Converter**

## 📌 About the Project

eng --> arabic is a Python tool that helps users fix text typed using the wrong keyboard layout.

For example, if you intended to type Arabic but your keyboard was set to English, this tool can convert the mistyped text into Arabic.

Just press **F8** to convert the text!

## ✨ Features

- Convert mistyped English keyboard input into Arabic.
- Support for Arabic and English keyboard layouts.
- Simple conversion using the F8 key.
- Built with Python.

## 🛠️ Requirements

- Python 3.14 or compatible version.
- `keyboard`
- `wordfreq`

## 📥 Installation

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required libraries:

```bash
py -m pip install keyboard wordfreq
```

## ▶️ How to Run

Run the following command:

```bash
py smart_keyboard.py
```

## ⌨️ How to Use

1. Run the program.
2. Type your text using the wrong keyboard layout.
3. Press **F8** to convert the captured text.
4. Press **ESC** to exit the program.

## ⚠️ Notes

- This is an experimental project, and conversion accuracy may vary.
- The program uses keyboard input monitoring to detect typed text.
- Avoid running it while entering passwords or other sensitive information.
- Windows may require administrator permissions for keyboard monitoring.
